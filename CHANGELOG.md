# Changelog

## 0.1.3 — Initial preview

- Local embroidery editor for Windows and Linux using installed Inkscape and Ink/Stitch.
- Drawing, SVG import, image tracing, embroidery lettering and outline fonts.
- Stitch previews, design checks, embroidery exports and PDF worksheets.
- Editable projects and project backup/restore.
- Windows installer, portable package and background launcher.
- First-run setup, tool selection and diagnostics.

Windows preview packages are unsigned.
