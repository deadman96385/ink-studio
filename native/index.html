YOUR WORK

Projects

A small studio guide

Compose. Text uses real embroidery fonts with visual previews. Return adds lines; alignment and line gap apply to the block. Edit an existing text layer to change its words, font or supported scale. Word spacing & stitch sequence adds an exact extra word gap, trim requests after lines/words/glyphs, and color sorting for fonts with indexed colors. Keep original thread colors to retain multicolor or appliqué steps.

Manage fonts. Font library & settings is in the font picker and Digitize. Import one Ink/Stitch font ZIP at a time, including font.json and its SVG variants. Inspect glyphs and licenses, mark favorites, hide unused fonts, and preview sample words or multiple lines as stitches. Font details & spacing edits baseline gaps, spaces, scale limits, direction, routing, glyph advances and kerning. A positive kerning value tightens a pair. Save as new font version keeps existing lettering on its previous version; Show hidden versions brings those copies back into the library. Project backups include custom fonts. Download font ZIP preserves the source variants and license.

Create and edit embroidery fonts. Digitize → Create & edit embroidery fonts starts a blank font, copies an installed one or restores a source font ZIP. Choose a glyph and Edit glyph artwork on canvas; Separate paths exposes individual shapes and stitches. The glyph panel controls its baseline, left origin and advance to the next character. Its guides never sew. Save glyph stores unfinished source work; Install font version checks it with Ink/Stitch and adds it to lettering. Previous workspace revisions and installed versions remain available. Copy/rename glyphs or copy direction artwork, then edit each direction’s stitch entry and order. Live gradients need Embroidery tools → Gradient → editable color blocks before saving as a glyph. Source ZIPs and glyph-project backups preserve font sources. Opening a glyph saves the previous design; Projects returns to it.

Convert and prepare fonts. In Font workspace → Start a new font, convert an SVG outline font using a reference character and millimeter height, or import stitched SVG/PES and other machine-format letters. Assign each file its character, ligature or alternate name; choose the left margin and how to retain trims and pauses. Outline conversion still needs digitizing before sewing; imported machine stitches retain their original size. Organize & prepare offers all eight glyph preparation stages, category sorting, lock-stitch rules, color indices and old SVG font-table cleanup. Review changes, then Apply to create a restorable source revision. Duplicate names can be repaired by selecting each source and renaming or removing it. Workspace spacing & behavior edits kerning pairs and glyph advances in millimeters, including space characters. Install a new font version to use updated source settings in lettering.

Font sample sheets. Digitize → Generate font sample sheets (or Font library → Create sample sheets) samples actual glyphs, including alternate forms and ligatures. Choose direction, scale, spacing, row width, trims and indexed color sorting. Unlocked glyphs start selected; tap to include or exclude others. Rows align to the baseline and split into 100 mm hoop pages. Jobs keep running when the dialog closes or the browser refreshes. Generated sheets offers page previews, PES downloads, editable backups, print keys, a complete ZIP and Save all to Projects. Editing a copy saves your previous design. Repeating Save all preserves existing saved edits. Sorted sheets are combined SVGs; Separate paths exposes their individual paths.

Arrange. Select multiple layers to align edges or centers, stack with an exact gap, or distribute gaps in either direction. Group layers to move them together; tap a member in Stitch order to edit it individually.

Move & protect. Drag to move, pinch to zoom and pan, or enter position/size/rotation in Layer. Arrange has exact nudging, mirroring and group rotation. Lock finished layers to prevent accidental changes; select them in Stitch order to unlock.

Thread palettes & lists. Layer or Digitize → Thread brands & colors offers palette editing and GPL import. Create a thread palette lets you name, number and reorder your own colors. Thread order & color lists imports TXT, EDR, COL or INF, matches catalog numbers or nearest palette colors, and previews changes in sewing order. Apply keeps a colored SVG copy and hides the originals; Undo restores them. Separate SVG paths edits individual copy paths. Split gradients/tartan into color blocks before applying a list.

Print & PDF workspace. Preview & export → Print / PDF sheet offers client overview/detail, operator overview/detail, a full-page pattern and custom instructions. Choose Letter or A4, job details, printed thread names and notes, time/thread estimates, logo and formatted footer. Artwork placement supports Fit, 100% actual size, exact scale/offsets, dragging with Pencil or a finger and pinch scaling. Simple/realistic rendering is independent for each view. Prepare pages to review the actual PDF, then download it or use Share → Print on iPad. Use 100% printer scale for an actual-size pattern. Save settings to design keeps them in its export and portable backup; reusable defaults keep page setup, estimate factors and branding. Printing does not change the stitches.

Test swatches. Digitize → Generate test swatches builds a numbered comparison sheet from selected artwork or a simple fill, satin, running or zigzag sample. Vary one setting across the sheet, or two by columns and rows. Set increments, gaps, sewing order and optional number labels, then preview the actual stitches. Create swatch project saves your original design separately. Edit this swatch sheet changes the saved recipe; Undo restores the previous samples. Print / PDF sheet includes each sample’s settings. Specialty parameters use selected artwork with that stitch method; enable the underlay or texture feature on the source before comparing its settings.

Fill & outlines. Set thread, stitch type, density, angle and underlay in Layer. Expand Outline over fill for a separate running, bean or zigzag outline. Fill compensation and trim/pause controls are in expandable sections.

Images and repeated layouts. Preview & export → More file formats offers simple and realistic PNGs, DPI, line width and transparent/fabric/custom image backgrounds. ZIP lets you choose file types, a filename and horizontal/vertical repeats with spacing between origins. Review the finished layout before downloading; PP1 output stays within 100 × 100 mm. SVG and project backups retain the single original design. Larger layouts require the other-machine destination.

Background. Fabric color only changes the preview. A stitched background can be fitted to visible artwork with an exact padding, then edited or removed independently.

Masks and shape crops. Select artwork, then Digitize → Prepare SVG artwork. Bake imported masks and clipping into editable paths, or release them. Mask cutoff chooses how much of a fading mask becomes embroidery; preview before applying. To crop your own design, draw a closed boundary, select the artwork to crop, choose Crop with a shape, and pick the boundary. Keep inside or outside, and hide the boundary so it does not sew. Use Editable needle points for cropped satin, ripple or zigzag. Hidden sources and Undo recover the original. Projects has mask and crop examples.

Place embroidery commands. Digitize → Positions & commands places stitch entry/exit, targets, routing and cut points, trims and pauses. Tap with a finger or Pencil, enter millimeters, or place a symbol around the outline or near a corner. Select multiple compatible layers to place or remove their commands together. Ignore primary path leaves an independent outline sewing; Ignore entire layer keeps the artwork visible but excludes all of it from embroidery. Command symbol display controls visibility, size and connection lines on the canvas and editable SVG. Guide & pattern marker display controls helper and needle-point icons separately; Guides & patterns also links directly to these controls. Imported helper paths can be shown in the canvas and editable SVG. Hiding a marker keeps the helper active; hiding its layer disables its effect. These display settings never change stitches. Whole design edits the export origin and frame-out position, including imported markers. Separate SVG/lettering paths exposes inner object commands. Linked copies follow their source; edit that source or detach the copy. Apply commits changes and Undo restores them.

Inspect the sewing sequence. Preview & export opens the native simulator. Step or enter a needle-stitch number, jump to a trim/stop/color change, reverse playback, change speed or pause at commands. Touch drag and pinch move the view; a Pencil tap or a tap without dragging selects the nearest stitch. Display settings control needle points, jumps, command markers, crosshair, line width and background. The reference hoop is centered on the machine origin. Tap a thread step to inspect its start. Selected artwork previews and downloads only the chosen visible artwork and its helpers; the saved design stays intact. Display settings never change embroidery stitches.

Find and locate problem shapes. Digitize → Troubleshoot objects (also in Check) reports errors, warnings and object-type issues with explanations, repair steps and iPad tool directions. Search/filter the report and use Locate on canvas to select and zoom to the source layer. Pointer/text sizes, labels and visibility are adjustable. Saved reports, Undo/Redo, portable backups and annotated SVG downloads are supported; editing artwork hides stale pointers until you check again.

Inspect density on the canvas. Digitize → Density map on canvas (also in Check) offers separate red/yellow radii and thresholds, indicator size, selection scope and artwork visibility. Generate a saved map, then close the panel to zoom and pan. Apply display changes, hide/remove the map, or download an annotated SVG. Undo/Redo is supported; editing embroidery hides stale maps until regeneration. Display choices do not change your PES. This uses Ink/Stitch’s pre-export plan; the existing Check density preview measures final PES.

Inspect each embroidered object. Digitize → Object stitch information (also in Check) reports stitch type, method, dimensions, counts, removed short stitches, jumps and stitch lengths for the whole design or selection. Search/filter the objects, expand details, select their source layers, copy the table or download TSV. Text/SVG pieces are listed separately. The report uses Ink/Stitch’s pre-export figures; Preview & export shows final PES counts. Inspecting SVG clones keeps your saved links intact, and cutting-needle assignments are included for cutwork.

Number the sewing order. Digitize → Order numbers on canvas (also available in Arrange) numbers the individual paths inside visible embroidery, text and SVG imports. Choose the whole design or selection, set label size, and show/hide or remove numbers with Undo. Editing the design hides old numbers until you regenerate them. Numbers mark first path nodes, not needle entry commands. Download numbered SVG keeps the labels in a non-sewing layer; overlays are also saved in project backups.

Compare stitches with artwork. Digitize → Stitch-plan overlays creates line or realistic previews at original document coordinates or beside the hoop. Show, dim or hide the artwork; lock/unlock a snapshot to drag it or enter exact offsets. Keep or replace previews, remove them and use Undo. Snapshots are saved with the project and do not sew. Regenerate after changing the artwork. Make stitches editable creates a needle-path copy at the original position and keeps the source hidden; separate its paths to edit individual stitches.

Turn stitch directions with artwork. Arrange → Move, mirror & rotate → Rotate / mirror stitch directions previews a rotation or mirror around the selection's shared center. Choose whether fill directions turn too or remain fixed on the fabric. Attached guides, gradients and stitch positions move with the shapes. Keep hidden source copies to retain editable native lettering and shapes; Undo also restores the originals. Results are SVG layers. Use Separate paths to expose their individual stitch settings.

Clean document settings. Embroidery preferences → Clean document settings reviews design-wide changes before applying. Reset this design’s embroidery preferences, clear native print settings and imported print/document metadata, or remove export origin and frame-out positions. Path stitch settings, pauses and native lettering stay editable. Hidden SVGs and saved lettering guides are included; other saved projects keep their original SVG copies. Undo restores the previous design.

Save & sew. Save keeps a project in your Studio data folder. Projects also offers Save as copy and an editable backup, even before stitches are generated. Preview creates real stitches and a PES for the existing Respira workflow in Bluefy.

Digitize. Draw editable paths or select a shape and tap Digitize → Edit nodes. Drag nodes and curve handles, or use Select multiple nodes / Box select to edit several together. Choose Corner for independent handles, Smooth for aligned handles, Symmetric for equal lengths, or Auto-smooth to follow neighboring nodes. Retract handles clears them; Handle coordinates offers exact positions in mm. When deleting nodes, fit the curve, retain handles or join with a straight segment. Review the shape-change estimate and original-path overlay. Join or merge endpoints, break paths, insert midpoints, straighten segments, or move/align/rotate/scale selected nodes. Local Undo restores geometry, node types and selection. Pinch to zoom. Offset / inset paths and Stroke area → fill offer physical dimensions and stitch previews. Divide shape and Cut outline use the later selected layer as a cutter. Apply commits the edit; Cancel keeps the source.

Holes & satin. Select two shapes, then Cut hole to subtract the later layer from the earlier one. Union, intersection, exclusion, combine, break apart and simplify are also available. Satin column opens two editable rails with crossing direction rungs. Rebuild the rungs after changing the rails, then check the stitch preview.

Curved text & imported paths. Create a lettering block and a guide path, then choose Create curved lettering. Multiline text follows parallel offsets of the guide; Extra line gap controls their spacing. Its source text and guide stay in Stitch order. Select the curved layer to edit words, placement or spacing again. Separate SVG / lettering paths exposes individual paths for node, color and stitch edits. Fill patterns include tatami, contour and circular.

Batch lettering & export. Under Digitize, make up to 128 names or multiline designs from a pasted or imported text list. Use blank lines between multiline entries, or choose a custom separator. Keep the current artwork as a template, replace its lettering, or follow a guide. Export saved designs together too. Results provide real stitch previews, individual files, a complete ZIP and editable copies. Completed designs remain available after cancellation or a service restart; Continue / retry finishes unfinished entries.

Reference images & tracing. Import a PNG, JPEG, HEIC or other supported picture. It starts locked behind the artwork and never sews. Unlock it to change position, size, rotation, opacity or crop. Draw over the reference keeps it fixed while you use Pencil. Trace image to editable paths offers color regions, a one-color silhouette or running centerlines, with detail controls and an actual stitch preview. Apply adds editable paths; Undo restores the previous design. Re-trace can replace the earlier result. Project backups include the source image; machine files and the embroidery SVG contain only stitched artwork and its helpers.
